# Support

## Current status

`Astraive/glint-library` is a **foundation-stage** repository. **No themes, registry, or release is available yet.** See [README.md](README.md) and [CHANGELOG.md](CHANGELOG.md).

## Where to get help

- **Using Glint, or app, SDK, and package-format bugs:** use [`Astraive/Glint`](https://github.com/Astraive/Glint) and its [discussions](https://github.com/Astraive/Glint/discussions) when enabled. Glint itself is also pre-implementation.
- **This repository's scripts, workflows, or documentation:** open an issue using the forms in `.github/ISSUE_TEMPLATE/`.
- **Theme submissions:** read [CONTRIBUTING.md](CONTRIBUTING.md). Submitting is optional; independent Git repositories and `.glint` files are fully supported by Glint.
- **Security vulnerabilities:** do not ask publicly. Follow [SECURITY.md](SECURITY.md).

## Support boundaries

- Support is a tested combination, not an OS logo. Theme platform claims must name the environments they were tested on. Windows 11 is the only current test host; Linux and macOS are compile-checked in CI only until real hardware exists.
- Third-party themes are supported by their authors. A theme listed here is not endorsed beyond its stated review level.
- Never upload personal media, unlicensed assets, or unredacted local paths to a report.
